# 虚拟背景图库

本目录的图片由 [`scripts/make_backgrounds.py`](../../scripts/make_backgrounds.py)
**程序化合成**，不是网络素材：

```bash
python scripts/make_backgrounds.py          # 已存在则跳过
python scripts/make_backgrounds.py --force  # 全部重新生成
```

## 为什么不用现成照片

答辩材料里"背景素材从哪来"是一个会被追问的问题。合成图**没有版权与肖像权负担**，
体积只有几十 KB、全部入库，且固定随机种子（`SEED = 20260922`）保证可复现。

## 内容

| 文件 | 类型 | 用途 |
|------|------|------|
| `01_暖色渐变` / `02_冷色渐变` / `03_深色渐变` | 线性渐变 + 四角压暗 | 最常见的虚拟背景观感 |
| `04_虚化暖光` / `05_虚化冷光` | 随机光斑 + 大幅模糊 | 模拟大光圈散景 |
| `06_浅灰网格` / `07_蓝灰条纹` | 简洁几何 | 高对比细节背景，便于观察边缘质量 |
| `08_纯白` / `09_浅灰` | 纯色 | 证件照、正式场合 |
| `10_绿幕` | 标准绿幕色 `#00B140` | 抠像演示；也是检查边缘镶边最明显的底色 |

## 加自己的背景图

把图片（jpg/png/bmp/webp）直接放进本目录即可，GUI 的图库列表与
`scripts/run_pipeline.py --seg-bg` 都会自动识别。目录里的非图片文件
（如本 README）会被自动过滤。

> 用真实照片（办公室、书架等）观感更接近腾讯会议，但请自行确认版权，
> 若画面中含可识别人物还需取得肖像权许可。
