# 自适应画质优化（AutoEnhance）实现计划

## 定位

新效果 `autoenhance`：**全时段**的经典 DIP 自适应画面优化——分区自动曝光、对比度、白平衡、饱和度。与现有 lowlight（均值<60 才触发的极端暗光线）互补不冲突：本效果处理逆光脸黑、轻微过曝、偏色、整体发灰等常态问题。算法全部为经典数字图像处理（直方图统计 + gamma 校正 + CLAHE + 灰世界假设），不引入新模型，呼应"回归 DIP 本质"。

## 算法设计（core/effects/autoenhance.py）

**人脸/背景分区**：复用 `beauty.py::face_oval_mask()`（FaceMesh 轮廓多边形，多人脸取并集），高斯羽化 ~11px 作软掩膜 m。`needs = {NEED_FACES}`——美颜默认已在跑 faces 推理，**零额外推理成本**；无脸时退化为全图按背景目标处理。

**处理链**（每步一个可单测的纯函数，模块顶部集中调参常量）：

1. **分区直方图统计**：LAB 空间 L 通道，分别在人脸区（m）与背景区（1−m）统计均值与 1%/99% 百分位（`cv2.calcHist` 或 masked 均值）。
2. **自动曝光（分区 gamma）**：γ_face = log(target_face/255)/log(mean_face/255)（人脸目标亮度 ≈150，相机 AE 人脸优先典型值；背景目标 ≈115）。目标±12 容差带内不校正（防常态抖动），γ 裁剪 [0.4, 2.5]。应用：两个 256 项 LUT（幂变换），按软掩膜逐像素混合 `lut_f[L]*m + lut_b[L]*(1−m)`。
3. **对比度**：CLAHE 作用于 L 通道（`cv2.createCLAHE`，clipLimit 由参数映射 0.5~3.0，tile 8×8）。
4. **色调/白平衡**：灰世界假设——**在背景区估计**各通道增益（人脸肤色会污染估计）g_c = gray_mean_bg / mean_c_bg，裁剪 [0.8, 1.25]，作用于 BGR。
5. **饱和度**：LAB 域就地缩放 a/b 通道（以 128 为中心）×(1+s)，零颜色空间转换成本。
6. **时域稳定**：γ_face、γ_bg、WB 增益做参数级 EMA 平滑（默认 0.8）——统计量平滑而非图像平滑，是相机 AE 的标准做法；`reset_temporal()` 清空。无跨帧图像缓存，帧尺寸变化天然安全。

**流程顺序**：BGR → WB 增益 → LAB → L 分区 gamma → CLAHE → a/b 饱和 → 回 BGR → strength 与原图混合。

**参数**（GUI 全暴露）：`strength`（总强度 0~1，默认 0.8）、`face_exposure`（人脸曝光优先 0~1，默认 0.7）、`contrast`（CLAHE 0~1，默认 0.3）、`color`（白平衡 0~1，默认 0.5）、`saturation`（0~1，默认 0）、`smooth`（时域平滑 0~0.95，默认 0.8）。

## 测试用例

- `gamma` 求解：暗→γ<1 提亮 / 亮→γ>1 / 容差内→1.0 / 裁剪边界；全黑全白帧不 NaN 不崩（对齐 AGENTS.md #17 教训）
- 灰世界增益：偏色图增益方向正确 / 灰图全 1 / 掩膜版只在指定区估计
- 分区曝光：合成"暗脸亮背景"图 → 处理后脸区均值显著上升、背景基本保持
- CLAHE：低对比图极差/std 增大；contrast=0 时恒等
- 人脸掩膜：合成 landmarks 掩膜内外正确 / 无脸退化路径
- 饱和度 a/b 缩放后方差增大
- strength=0 对象同一透传；EMA 收敛与 reset_temporal 清空
